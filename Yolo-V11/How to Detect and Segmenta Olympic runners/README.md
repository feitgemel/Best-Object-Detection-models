<font size= "4" >
Stop wasting hundreds of hours labeling images. In this tutorial, we are building a Pro-Level AI Sports Tracker using a "Zero-Shot" approach. That means we are performing high-end detection and segmentation with zero manual dataset preparation. 

We leverage the power of GroundingDINO to understand what an "Olympic Runner" looks like automatically, then we distill that knowledge into a lightning-fast YOLO11 model. To finish it off, we integrate Meta’s SAM (Segment Anything Model) for professional, broadcast-quality segmentation masks.

This video is designed for AI researchers, CS students, and Python developers looking to upgrade their Computer Vision toolkit with the latest models .

🔍 What You’ll Learn:

✅ How to stream and save YouTube frames using VidGear. <br/> 
✅ Automating dataset creation with Autodistill & GroundingDINO. <br/> 
✅ Training a custom YOLO11 nano model on your own data. <br/> 
✅ Using SAM (Segment Anything) to add masks to YOLO detections. <br/> 
✅ Training: Powering through 300 epochs with YOLO11. <br/> 
✅ Python implementation with OpenCV and PyTorch. <br/>
